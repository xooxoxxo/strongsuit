## JavaScript Weekly / Node Weekly (Cooperpress) — verified

- Submit: https://cooperpress.com/submit
- Pitch:

> strongsuit (Node ≥ 20, TypeScript, MIT) is a CLI for Claude Code users who installed too many skills and MCP servers. It groups them into named suits and switches them with one command, by symlink and a ledgered JSON write that never touches keys it did not write. Remote suits pass a per-component review and are pinned by sha256; drift blocks with a diff. `suit run` scopes a suit to one session. Cross-platform, including Windows junctions. 348 tests on five CI legs. Token figures are estimates, and the docs say so. https://github.com/xooxoxxo/strongsuit
